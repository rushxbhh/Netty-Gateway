Transatlantic Connection Pooling Impact (Case Study)

Eliminating per-transaction TLS 1.3 handshakes between India and AWS us-east-2 (Ohio)

88% LATENCY REDUCTION
BEFORE (Per-Transaction Connection) ~2,500 ms

Every incoming transaction executed DriverManager.getConnection(), performing a full TCP 3-way handshake + TLS 1.3 key exchange across 12,500 km of fiber to Ohio on every single insert.

AFTER (Warm Reused Connection) ~262 ms

Persistent connection reuse via getOrCreateConnection() keeps the TLS socket open across transactions. Inserts execute at the raw optical fiber ping floor with only 19 ms standard deviation.
